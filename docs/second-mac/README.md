# Второй Mac — Parrot работает

Обновлено 2026-10-06. MacBook Pro — Nikita: Apple M2 Pro, 16 ГБ RAM, macOS 27.0.1.

Это последняя проверенная установка второго Mac, а не новое подтверждение его текущего runtime-состояния. Выпуск [2026-10-09](../performance/improvement-2026-10-09/README.md) установлен только на основном M5 Pro; второй Mac в нём не менялся.

## Текущий статус

После переноса исходной рабочей версии Parrot обновлён до **Parakeet Ultra / FluidAudio 0.17.3** вместе с основным Mac. Одинаковые подписанные приложения — в `/Applications/Parrot.app`; итоговый SHA256 и путь резервной старой версии — в [статусе](../parakeet-ultra/status.json).

Пользователь завершил onboarding и разрешил микрофон и системный звук. После обновления оба источника проверены production AudioCaptureManager. Окно Parrot выведено вперёд, Dock включён. RU/EN/PL, VAD/utterance pipeline и Whisper fallback прошли локальные тесты в приложении без сетевых разрешений.

Данные обновления — в [Parakeet Ultra](../parakeet-ultra/README.md). Эта папка хранит доказательства первоначального переноса.

## Модели

- Ultra: 20 файлов, размеры и хеши проверены; кэш `FluidAudio/Models/parakeet-ultra`.
- V3: неполный стандартный кэш завершён из проверенного кэша основного Mac, 23 файла; первоначальный legacy-кэш сохранён.
- Silero VAD: доступен в корректном каталоге `silero-vad`.
- Whisper Large V3 Turbo: 24 файла, 1 638 464 446 байт, `argmaxinc/whisperkit-coreml`, revision `0f63a7800b00dd0226abd051b906c246e1907482`. Best Transcript первоначально проверен на RU/EN/PL. Live fallback после исправления работает без сети из готового кэша.
- Qwen 3.5 9B: 5 060 174 144 байта, SHA256 `f41c0a0c0e43bf721fb2da29374cd1a97271bac0bab08a9dc42964525e82350c`. Точный bundled runtime в sandbox-родителе сгенерировал русское название. Production-защита RAM может откладывать названия/сводки — см. ограничение Ultra.

## Возобновление

Использовать `home-mac` или проверенную кабельную SSH-связь из документации Ultra. История встреч и ключи с основного Mac не переносились. DNS, VPN и маршруты не менялись.

Старый Parrot имел зависающие CLI-режимы с DispatchSemaphore. В установленном обновлении `--parakeet-test`, `--whisper-fallback-test`, `--call-pipeline-test` исправлены. Старую резервную сборку для них не использовать. Первоначальный неудачный sandbox-exec не является offline-доказательством; новые проверки с запрещёнными сетевыми entitlement прошли.

[Исходные контрольные суммы](source-checksums.json), [перенос приложения](app-transfer.log), [перенос Qwen](title-model-transfer.log), [первоначальный журнал ресурсов](resources.json). Тестовые аудио содержат синтезированные фразы. Временные помощники убраны, приложение оставлено запущенным.
