## Результат

На основном Mac и MacBook Pro — Nikita (M2 Pro, 16 ГБ) установлен одинаковый подписанный Parrot: **Parakeet Ultra**, FluidAudio **0.17.3**, резервный Whisper Large V3 Turbo. История встреч и разрешения сохранены.

Оба приложения запущены. Основной Mac показывает Ready to record. На втором подтверждены GUI-сеанс, Dock и видимое окно. После установки на каждом Mac проверены микрофон и системный звук точным production AudioCaptureManager; диагностические дорожки удаляются, встреча в базе не создаётся.

## Проверки

- 208 unit tests прошли на версиях зависимостей итоговой сборки. Существующие проверки уведомлений заменили ненадёжные ожидания 30 мс на ожидание состояния с ограниченным сроком; код уведомлений не изменялся.
- A/B V3 и Ultra: одинаковые синтетические RU/EN/PL записи, по два повтора на каждом Mac. Число ошибок одинаково: расхождение в написании «Паррот» в русской фразе. Это проверка совместимости, не оценка точности на реальных встречах.
- A/B, production VAD/utterance pipeline и Whisper fallback прошли в тестовой копии исполняемого кода с запрещёнными сетевыми entitlement. Интернет системы не отключался. [Entitlement тестовой копии](evidence/offline-test-entitlements.json).
- Исправлена проблема live fallback: Whisper теперь выбирает готовую локальную модель, скачивание разрешается только при её отсутствии. Offline-тест падал на обоих Mac до исправления и прошёл после него.
- На втором Mac завершён неполный стандартный кэш V3 и исправлен каталог Silero. Ultra хранится в `FluidAudio/Models/parakeet-ultra`, без `-coreml`.

## Модель и скорость

Ultra — дообучение NVIDIA Parakeet V3 от Moondream. Поддержка Core ML вышла [24 сентября](https://github.com/FluidInference/FluidAudio/releases/tag/v0.17.3). [Карточка модели](https://huggingface.co/FluidInference/parakeet-ultra-coreml) заявляет снижение средней ошибки FLEURS с 14,81% до 11,67% при близкой скорости. Наш небольшой тест этого улучшения точности не доказывает. На M2 медиана декодирования Ultra была 0,099 с против 0,100 с у V3; замеры основного Mac имели выбросы во время параллельной сборки.

Все 20 файлов, 632 314 500 байт, revision `95eaa59a39d4394f047a4dc5cce480388a60d1b6`, проверены по размерам и хешам: [манифест](model-manifest.json). Передача на второй Mac — шифрованный SSH по кабелю. DNS, VPN и маршруты не менялись.

## Ограничение второго Mac

Запись и распознавание проверены. Qwen 3.5 9B для названий/сводок использует прежнюю защиту памяти: запуск требует 10 ГБ доступных для освобождения страниц. Последняя проверка второго Mac дала около 4,9 ГБ, поэтому автосводка может откладываться. Защита не ослаблялась; установка Ultra не доказывает доступность автосводки при текущей загрузке RAM. Native runtime Qwen проверен ранее: [второй Mac](../second-mac/README.md).
