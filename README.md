# 🦜 Parrot — личная локальная сборка

Parrot записывает системный звук и микрофон на Mac, показывает расшифровку во время разговора и сохраняет отдельную итоговую версию после Stop. Аудио, история встреч и текст хранятся на устройстве. Облачные распознавание, polish и copilot отключены в [PersonalBuildPolicy](Parrot/Services/PersonalBuildPolicy.swift), включая старые сохранённые настройки.

## Текущее состояние

На основном **MacBook Pro M5 Pro, 64 ГБ** установлен и проверен выпуск **2026-10-09**; передача результата завершена 2026-10-10. Источник текущего состояния: [отчёт выпуска](docs/performance/improvement-2026-10-09/README.md), [STATE](docs/performance/improvement-2026-10-09/STATE.md), [откат](docs/performance/improvement-2026-10-09/ROLLBACK.md).

- Исправлены публикация состояния захвата, Stop/выход, отмена фонового распознавания и синхронизация эха.
- Whisper обрабатывает до четырёх окон; новая запись получает приоритет над фоновыми задачами.
- Новые встречи автоматически получают Final. На основном Mac используется Whisper + Qwen3-ASR для окон со сменой языков. Live и аудио доступны отдельно; старые встречи автоматически не перерабатываются.
- Пройдены 258 тестов, запись обоих источников, локальное распознавание без сетевых разрешений, сохранение, воспроизведение и выход во время записи. Исходные 88 встреч и 21647 Live-сегментов сохранены без изменения.
- На объявленном синтетическом наборе: 3 ошибки на 473 слова против 14 у Whisper. Отдельный английский контроль показал около 11% прироста пропускной способности пакетного Whisper. Это ограниченные измерения; итоговый hybrid-проход занимает больше времени ради качества.

Физическое нажатие Quit в статусном popover осталось вне возможностей UI-автоматизации. Его отложенный обработчик проверен тестом; обычное меню Quit и Cmd-Q проверены в приложении. Второй Mac этим выпуском не менялся; его последняя проверенная установка описана в [историческом отчёте Ultra](docs/parakeet-ultra/README.md) и [переносе на второй Mac](docs/second-mac/README.md).

## Использование

1. При первом запуске разрешить Microphone и Screen Recording в настройках macOS. Parrot использует ScreenCaptureKit для системного аудио.
2. Загрузить локальные модели через onboarding или Settings → Download / Reload Local Models. Интернет нужен для недостающих файлов; готовые модели работают локально.
3. Начать запись, завершить через Stop и дождаться сохранения. Final готовится в фоне; новую запись можно начать во время обработки.
4. Открыть встречу, выбрать Final / Live, воспроизвести аудио или экспортировать текст/субтитры. Позиции итогового текста приблизительные; это явно показано в интерфейсе.

Qwen3-ASR для Final устанавливается отдельно после проверки качества; простое скачивание live-моделей его не выбирает. На новой установке без принятой native-модели Final использует локальный Whisper. Порядок подготовки — в [сборке и проверке](docs/BUILD.md).

## Компоненты

| Назначение | Реализация |
|---|---|
| Интерфейс и история | SwiftUI, SwiftData / SQLite |
| Системный звук / микрофон | ScreenCaptureKit / AVAudioEngine |
| Live | Parakeet Ultra, FluidAudio 0.17.3, Silero VAD |
| Резервное и пакетное распознавание | Whisper Large V3 Turbo, WhisperKit 0.18.0 |
| Итоговая смена языков | Qwen3-ASR 1.7B 8-bit в отдельном локальном MLX worker |
| Локальные названия встреч | Qwen 3.5 9B, встроенный llama runtime |
| Проект Xcode | XcodeGen; источник конфигурации — project.yml |

Рабочая сборка — Apple Silicon, deployment target macOS 14+. Выпуск проверен с Xcode 27 / Swift 6.4 на основном M5 Pro; совместимость с другими конфигурациями требует своей проверки. Guard для Qwen 3.5 9B — 10 GiB, для native ASR — 6 GiB; ограничения второго Mac сохранены.
